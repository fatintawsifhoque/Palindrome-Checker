#  Palindrome Checker

A real-time, responsive Palindrome Checker built with **React** and **Tailwind CSS**. 

This project focuses on managing side effects and state synchronization using React Hooks, ensuring a smooth and bug-free user experience.

---

### ✨ Features

- **Real-Time Validation:** Instantly checks if the input is a palindrome as the user types.
- **Dynamic Visual Feedback:** Conditionally renders green or red text colors based on the validation result.
- **Edge Case Handling:** Properly handles empty inputs and single-character strings.
- **Clean UI:** Features a minimal, centered design with smooth focus states and responsive typography.

---

### 🛠️ Tech Stack

- ⚛️ **React** (Functional Components & Hooks)
- 🎨 **Tailwind CSS** (Utility-first styling)
