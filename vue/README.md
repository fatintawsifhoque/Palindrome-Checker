# 🔍 Palindrome Checker

A real-time, responsive Palindrome Checker built with **Vue 3** and **Tailwind CSS**. 

This project demonstrates how to handle reactive state changes and string manipulation elegantly using Vue's Composition API.

---

### ✨ Features

- **Real-Time Validation:** Instantly checks if the input is a palindrome as the user types, without needing a submit button.
- **Dynamic Visual Feedback:** Uses conditional styling to display success (green) or error (red) text based on the result.
- **Edge Case Handling:** Gracefully handles empty inputs and single-character strings to prevent false positives.
- **Clean UI:** Features a minimal, centered design with smooth focus states and responsive typography.

---

### 🛠️ Tech Stack

- ⚡ **Vue 3** (Composition API with `<script setup>`)
-  **Tailwind CSS** (Utility-first styling)
